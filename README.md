# BookNook

BookNook is a web app that allows users to find free e-books from Project Gutenberg and save and access them on their personal reading list.

## What the page does and who it is for

The target group is the general public. It encourages a sense of cozy calm suitable for creating a cozy space for reading no matter the age, gender identity, or preference.

## API and Necessary Configurations

The API used for this project is Gutendex which is a JSON web API for Project Gutenberg's ebook metadata.

Read the documentation here: https://gutendex.com/
